*Organizador de Tarefas*

Projeto desenvolvido em equipe para criar um sistema de organização e gerenciamento de tarefas.

Versão 1.0.0 — Primeira versão

Sobre o Projeto

O Organizador de Tarefas tem como objetivo facilitar a criação, organização e acompanhamento de tarefas do dia a dia.

Nesta primeira versão, foi desenvolvida a estrutura inicial do sistema, com funcionalidades básicas para gerenciamento das tarefas e armazenamento dos dados.

Tecnologias
Python — desenvolvimento da aplicação
JSON — armazenamento e organização dos dados
Git — controle de versão
GitHub — hospedagem e colaboração do projeto
Funcionalidades
Adicionar tarefas
Listar tarefas
Marcar tarefas como concluídas
Remover tarefas
Salvar tarefas em JSON
Carregar tarefas ao iniciar o programa
